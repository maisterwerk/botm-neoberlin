The two modes

Calm — an answer is fixed before you start, from the day's date. Ordinary Wordle, with the barometer running.

Storm — the host never commits to a word. Each time you guess it replies with whichever pattern keeps the most answers alive, so the field shrinks as slowly as the rules allow. It never lies: the surviving words are exactly those consistent with every reply so far, and the set is never empty. You can lose here. Six guesses is a real cap and a few weak questions can leave more candidates than you have turns — the barometer is what tells you that is happening while you can still do something about it.

Neither idea is original. Storm is Absurdle (qntm, 2022); the barometer is what NYT's WordleBot (2022) does after the fact. What is new is putting them together — the readout is the counter to the host — and running it live instead of in a post-mortem.
